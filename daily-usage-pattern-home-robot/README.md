# daily-usage-pattern-home-robot

[하루를 읽는 로봇: 일정한 생활 루틴에서 출발한 추천 서비스](https://analysis-archive.vercel.app/analyses/daily-usage-pattern-home-robot) 재현 코드.

가정용 실내 로봇의 사용 로그로 유저가 하루에 어떤 기능을 얼마나, 어떤 순서로 쓰고 그 하루가 얼마나 반복되는지 본 분석의 재현. 켜 두는 기능이 거리를 독차지하는 문제, 뚜렷한 덩어리가 없을 때의 k 선택, 하루 모양 셋, 기능을 새로 시작할 때마다 1회로 센 하루 순서, 기기마다 반복되는 하루와 기기마다 다른 음성 시각을 가상 로그로 다시 본다. 실제 로그는 없고 구조(제자리 모드 점유, 기본 스케줄 시각, 음성 위주 기기군, 기기별 패턴 일관성, 기기별 음성 시각)만 옮김. 분석 환경에 scikit-learn 이 없던 것을 따라 k-means, silhouette, ARI 는 numpy 로 직접 구현.

## 실행

```bash
pip install -r requirements.txt
for s in scripts/0*.py; do python "$s"; done
```

30초 남짓. Python 3.14.7, numpy 2.5.2, pandas 3.0.5, matplotlib 3.11.1, pillow 12.3.0. 같은 환경에서 두 번 돌려 결과 CSV와 생성 데이터가 byte 단위로 같았음.

## 스크립트

| | 역할 | 주요 출력 |
|---|---|---|
| 01 | 기기 1,500대, 평일 20일 사용 이벤트 생성. 기기 유형 셋, 하루 상태 셋, 기본 스케줄, 제자리 모드 끊김, 음성 피크 시각, 경계 흐림 | `data/devices.csv`, `events.csv.gz` |
| 02 | 기본 스케줄 휴리스틱 (9, 12, 15, 18시에 시작한 10분 미만 이동 모드), 이벤트를 (기기, 날짜, 시간, 기능) 셀로, 기능별 규모, 기기-일 구성, 시각 분포 | `data/cells.csv.gz`, `feature_scale.csv`, `day_composition.csv`, `overall_hour_share.csv` |
| 03 | 기기-일 행렬 (기능 9종 x 2시간 구간 12), 정규화 전후 분산 몫, k 3~8 의 inertia/silhouette 와 k 선택 | `data/target_days.csv`, `feature_variance_share.csv`, `k_sweep.csv`, `k_sweep_raw.csv`, `k_choice.csv` |
| 04 | 패턴 군집, 기능 사용률, 시각 분포, 기기-일 기준과 기기 기준 비중, 일관성 | `pattern_*.csv` |
| 05 | 사용 1회 (새로 시작할 때마다, 계속 켜져 있던 같은 기능만 이어 봄), 하루 사용 횟수, 하루 순서와 전이, 같은 기기 날끼리 순서 유사도, 기능별 첫 사용 시각 | `data/day_sequences.csv.gz`, `seq_*.csv`, `personal_*.csv` |
| 06 | 기기 1행 프로파일 (13항목) 군집, 단위별 silhouette, 유형 x 주 패턴 | `device_*.csv`, `silhouette_by_unit.csv` |
| 07 | ground truth 평가. 패턴과 기기 유형의 ARI, 기본 스케줄 휴리스틱의 정밀도와 기기 비율 부풀림 | `eval_*.csv` |
| 08 | 그림 15장 | `outputs/figures/site/fig1~15` |

`truth_*` 열은 판정(02~06)에 쓰지 않음. 07 만 읽음.

판단 기준: 하루 시작 2건 이상인 기기-일만 군집. k 는 silhouette 최대값과 0.03 안 중 가장 작은 k. 켜 두는 기능은 구간 점유 비율 (하한 0.1), 순간 기능은 구간 사용 여부, 기기-일마다 기능별 12칸을 길이 1 로 맞춤. 같은 기능이 끝나고 60초 안에 다시 시작되면 이어 켜진 것.

## 확인할 숫자

- 02: 제자리 모드 쓴 날 평균 10.6시간, 무사용 날 30.9%, 기록 1건 날 9.0%
- 03: 정규화 전 분산 몫 제자리 모드 62%, 음성 33% (정규화 뒤 19%, 27%). silhouette (정규화 뒤) 0.162~0.205, k=3
- 04: 비중 저녁 42.0%, 종일 34.3%, 음성 중심 23.7% (기기 기준 30.4 / 25.2 / 44.4%). 일관성 0.847~0.895
- 05: 하루 사용 중앙값 8회, 5회 넘는 날 76.3%, 앞 4개로 자르면 잘리는 날 82.8%. 음성 첫 사용 시각 기기 안 0.43시간, 기기 사이 4.64시간
- 06: 기기 단위 silhouette 0.340 (기기-일 0.205). 저활동 유형의 주 패턴 86.4% 가 음성 중심
- 07: 패턴 ARI 정규화 뒤 0.726 (전 0.750), 기기 유형 0.879. 스케줄 휴리스틱 정밀도 0.984, 기기 비율 실제 27.5% vs 한 번이라도 잡힌 기기 41.7% vs 10일 이상 24.7%

## 알려진 문제

- 재현의 기기 유형은 저활동과 활동, 거기에 작은 묶음 하나(38대)로 갈린다. 실제 분석의 셋째 유형(공간 스캔 매일)은 재현에서 따로 서지 않는다
- 재현의 패턴 크기 순서가 실제와 다르다 (실제는 종일 패턴이 기기-일 1위). 글에서는 번호 대신 이름으로 부른다
- 이동 모드와 센서 호출 모드의 시각은 기기마다 다르게 넣지 않았다
- 기기 쪽에서 실행된 명령 로그는 넣지 않았다. 기본 스케줄은 휴리스틱으로만 가린다
